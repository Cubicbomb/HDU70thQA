# 杭州电子科技大学 70 周年知识问答

《中国近现代史纲要》2026–2027 学年第一学期思政实践 · **主题二：纪念杭州电子科技大学建校 70 周年** · 电子程序类成果。

26040521 崔佳乐

纯静态网页：无构建、无后端、无第三方依赖。

## 如何运行

方式一（推荐）：在项目目录启动任意静态服务器，例如：

```bash
python -m http.server 8080
# 浏览器打开 http://127.0.0.1:8080/
```

方式二：直接双击 `index.html` 用浏览器打开（题库以 `data/questions.js` 全局脚本加载，支持 `file://`）。

## 页面与玩法

- **推荐动线（先读后答）**：封面点「校史 · 文化」（下方小字引导）→ 介绍页 `history.html` → 页内「开始答题」进入问答；也可封面「开始答题」跳过介绍。
- **介绍页 `history.html`**：校史沿革时间线、校训校风与精神基因、校园文化、学科成就摘要；读完可开答或返回封面。
- **问答 `index.html`**：
  1. 封面「校史 · 文化」进介绍页，「开始答题」直接开答（或从介绍页跳转）；
  2. 依次作答：**单选**、**趣味排序**（上移/下移）、**填空**（校训等）；
  3. 每题提交后显示对错与解析；顶栏可「再看看介绍？」（放弃本轮进度）；
  4. 结束后查看得分、正确率与错题列表，可「再答一次」或进入介绍页。

## 作者的话

这就是我的纲要课实践作业了。

因为要求中说「不接受完全以 AI 自动生成作业」，我觉得有必要为这个项目加上一些补充。

这个项目很大部分是使用 AI 搭建的，但在设计方面融入了很多我们自己的元素和风格，并没有完全丢给 AI 做。和 AI 一轮一轮对话、查看效果、一遍一遍测试、发现缺陷、提出优化方案、审核每次的改动，还是相当费时的。所以还是花了不少精力的。虽然看上去还是有很大 AI 味，但是很显然，搭建这样的一个项目，并不是向 AI 许个愿就能实现的。

我花了相当多的时间优化排版。也许这不止是一个问答程序，把他当作一个网页艺术作品也许更合适。

关于这个项目：

- 创新性地添加了校史排序的小题目。
- 把杭电的校徽标志融入进去也是花了相当多的精力。
- 70 周年相关的标志没能找到官方文件，所以可能有所欠缺。
