# 杭州电子科技大学 70 周年知识问答

《中国近现代史纲要》2026–2027 学年第一学期思政实践 · **主题二：纪念杭州电子科技大学建校 70 周年** · 电子程序类成果。

纯静态网页：无构建、无后端、无第三方依赖。

## 如何运行

方式一（推荐）：在项目目录启动任意静态服务器，例如：

```bash
python -m http.server 8080
# 浏览器打开 http://127.0.0.1:8080/
```

方式二：直接双击 `index.html` 用浏览器打开（题库以 `data/questions.js` 全局脚本加载，支持 `file://`）。

## 页面与玩法

- **介绍页 `history.html`**：校史沿革时间线、校训校风与精神基因、校园文化、学科成就摘要；封面与结果页均可进入，页内可返回封面或直接开始答题。
- **问答 `index.html`**：
  1. 封面点击「开始答题」（或从介绍页跳转）；
  2. 依次作答：**单选**、**趣味排序**（上移/下移）、**填空**（校训等）；
  3. 每题提交后显示对错与解析；
  4. 结束后查看得分、正确率与错题列表，可「再答一次」或进入介绍页。

## 目录结构

```
index.html          # 问答入口
history.html        # 校史 / 校园文化介绍页
styles.css          # 校庆深蓝 + 金 视觉（问答 + 介绍页共享）
app.js              # 状态机与判定逻辑
data/questions.js   # 题库（30 题）
docs/compose/spec/  # 功能规格
```

## 题目来源（史实抽核）

| 来源 | 用途 |
|------|------|
| 杭州电子科技大学官网《学校简介》《校史沿革》（Wayback Machine 2020 存档） | 建校年份、更名节点、共建体制、学科成就、美誉 |
